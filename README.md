# 群聊插话提示头

给核心主动回复通路加提示头：群消息没 @、没被唤醒时，告诉模型这是自己在插话，不是对方在跟自己说话。

> 从个人自用环境里抽出来开源的一份，发布前做过脱敏：所有 QQ 号、群号、本机绝对路径、token 都换成了空值或占位符。
> 装完记得按下面的说明填自己的。

## 安装

放到 AstrBot 的插件目录（`data/plugins/`）下，重载插件或重启 AstrBot 即可。AstrBot 4.24.0+，平台适配器 `aiocqhttp`。

## 配置

纯提示词注入，装上就行，没有需要填的东西。

## 说明

- 依赖 AstrBot 自带的 `astrbot.api`，不需要额外 pip 包。
- 日志写在自己插件目录的 `data/` 下，不会污染别处。
